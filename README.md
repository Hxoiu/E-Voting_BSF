# E-Voting System

A web-based electronic voting system designed to make the voting process faster, easier, and more organized.

## Installation

Clone the repository and install the required dependencies:

```bash
git clone <repository-url>
cd <project-folder>
npm install
```

## Run the Project

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Tech Stack

* React
* TypeScript
* Vite
* Node.js
* npm

## Notes

Make sure **Node.js and npm** are installed before running the project.
